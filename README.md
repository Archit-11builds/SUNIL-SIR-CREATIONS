# CBSE Study Hub — Vercel Edition

A premium Class 10 CBSE dashboard built with Next.js 14, React, TypeScript and Tailwind/PostCSS.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Deploy to Vercel
1. Push this folder to GitHub.
2. Import the repository into Vercel.
3. Vercel detects Next.js automatically.
4. Deploy.

## Included
- Animated-feeling premium orange/light UI
- Dark/light toggle
- Responsive sidebar/mobile layout
- Dashboard with real syllabus-derived progress
- Syllabus tracker
- Notes
- Revision area
- Official CBSE resource links
- Sunil Sir lecture/channel shortcut
- Analytics
- Client-side state for this demo

## Important
The Sunil Sir link is a channel-level shortcut. Replace it with exact chapter playlist/video URLs you want to use.
The next upgrade can add Supabase authentication and cloud-synced notes/progress.
